# Gestor de Playlist Circular
##Descripción
Programa en Java que administra una lista de canciones mediante una lista doblemente circular. Permite agregar canciones al inicio o al final, buscar y seleccionar canciones por ID, eliminar canciones, avanzar y retroceder entre canciones, mostrar la lista, consultar la cantidad de canciones y simular reproducciones.
##Requisitos
1.- Tener instalado el JDK de Java. 
2.- Entorno: Terminal/Consola o cualquier IDE (Eclipse, IntelliJ IDEA, VS Code, NetBeans).
## Versión de Java
Este proyecto utiliza sintaxis compatible con Java 8 o posterior. Se recomienda usar JDK 8 o una versión más reciente.
## Archivos del proyecto
Asegúrate de tener estos archivos en la misma carpeta:
- Cancion.java
- ListaReproduccion.java
- Nodo.java
- Main.java
##Desde un IDE (nosotros trabajamos con IntelliJ IDEA 2026.2.3)
Descarga la carpeta del proyecto
Abre la carpeta del proyecto en tu entorno de desarrollo preferido.
Abre el archivo Main.java .
Presiona el botón Run (ícono de reproducir) o utiliza el atajo de teclado correspondiente de tu IDE para ejecutar la aplicación en la consola integrada.
